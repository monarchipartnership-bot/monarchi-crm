# AI Agents: устройство раздела (спецификация владельца, 2026-11-02)

Собрано из описания владельца и обсуждения 2026-11-02. Это опорный документ: любые решения по разделу сверяются с ним. Статус: решения приняты, реализация по порядку в конце документа. Названия интерфейса украинские, пояснения русские.

## 1. Модель

**Проєкт → Кампанія → Цикл → Готові матеріали**
- **Проєкт**: карточка клиента, главная в **CRM → Проєкти** (кабинет, контакты, отчёты). В неё добавляется раздел для агентов («AI-агенти»), где живёт всё, что агентам нужно знать о клиенте. Второй карточки нет.
- **Кампанія**: задание агентам по проекту: тип, настройки агентов, расписание, лимиты. По одному проекту одновременно может идти несколько кампаний (стратегия плюс креативы, две кампании на креативы и т.д.), они не ломают друг друга.
- **Цикл**: один прогон кампании. Разовая кампания = один цикл. Кампания с расписанием = цикл повторяется. «% выполнения 1 цикла» считается по этапам цикла.
- **Готові матеріали**: одобренные креативы, стратегии, отчёты; скачиваются; лежат в карточке проекта, привязаны к кампании и циклу.
- **«Новий запит» на креативы исчезает**: запрос на креативы = разовая кампания «Тільки креативи» (завершённые разовые кампании уходят в «Завершені» внутри проекта).
- Результаты кампаний питают друг друга: **стратегия попадает в раздел «AI-агенти» карточки проекта после подтверждения владельца**, дальше её читают другие кампании.

## 2. Верхнее меню раздела AI Agents
1. **Мапа**
2. **Проєкти**: список проектов с настроенным AI-разделом; клик открывает ту же карточку CRM. Мастер создания (см. 4).
3. **Кампанії**: общий список всех кампаний, карточка кампании (см. 5).
4. **Витрати**
5. **Інформаційна база** (открывается поверх страницы)
6. **Стан системи** (новый): что сломано сейчас (ключи, лимиты, упавшие шаги, токены Meta/Higgsfield), история аварий, повторы.

### Мапа
- Районы, агенты, связи, клик на район/агента открывает его и настройки.
- **Машинки = реальные задачи.** Машинка это цикл кампании. Она стоит у того агента (квартала), где задача сейчас, подписана кампанией и типом, клик показывает её путь. В блоке «Рух задачі по відділах» (слева внизу) цепочка активной задачи и список всех активных задач, переключение выбирает машинку. Сейчас движение демо, реальных данных на карте нет.
- Справа внизу блок **«Активні кампанії»** (вместо «Активні проєкти»): сворачивается, показывает запущенные кампании и ведёт на них.
- Справа вверху поиск по разделу и «До Hub». Слева вверху название раздела; счётчики статусов агентов в финале убираются.

## 3. Данные проекта (раздел «AI-агенти» в карточке)
Одна форма, четыре источника. Каждое поле помечено, откуда оно берётся.

| Источник | Поля |
|---|---|
| **Кабинет Meta/Google (автоматически)** | название и ID кабинета, валюта, часовой пояс, статус, платформы, список кампаний, показатели, лучшие объявления |
| **Карточка проекта CRM (автоматически)** | название проекта и клиента, контакты, услуги, подключённые кабинеты |
| **AI-раздел (заполняется здесь)** | описание бизнеса, оффер и отличия, аудитория (сегменты), конкуренты, тон бренда, ограничения («чего нельзя»), бренд (логотип, цвета, шрифты), библиотека материалов (фото товара, примеры стиля), ссылка Figma, кнопка (CTA), языки и рынки, сезонность и акции, цели/KPI, диапазон бюджета, примеры креативов (ссылки, скриншоты) |
| **От агентов (после подтверждения)** | исследование бизнеса, конкуренты, аудитория, стратегия, результаты кабинета, замечания по трекингу |

У каждого агента есть список **обязательных и желательных полей** («матрица требований»). Если нужного поля нет, оно показывается как блокер: заполнить сейчас или при создании кампании.

## 4. Создание проекта (шаги 1–3)
- **Шаг 0:** «Створити проєкт» → выбор из проектов CRM с подключёнными кабинетами.
- **Шаг 1:** заполнение данных. Выбор **«Швидке заповнення»** (чат или голос: текст разбирается моделью и раскладывается по полям, показывается «Зрозумів так» для правки) или **«Ручне заповнення»** (все поля).
- **Шаг 2:** то, что нельзя сказать голосом (ссылки, файлы, примеры креативов): система сообщает об этом и выносит эти поля сюда. Незаполненные важные поля: уведомление «заполнить сейчас или при создании кампании».
- **Шаг 3:** «Створити кампанію» или «Зробити пізніше» (проект сохраняется и закрывается).

## 5. Создание кампании (шаги 4–6) и карточка кампании
- **Шаг 4:** тип кабинета и тип кампании (Повна, Тільки креативи, Тільки стратегія, Аналіз і оптимізація, Тільки звіт), схема агентов со стрелками.
- **Шаг 5:** настройка агентов, быстрая через чат или голос. Агенты берут данные из карточки; чего нет, показывается и запрашивается. Для креативов: **количество (без лимита) и форматы**. Расписание. Лимит денег (необязательно, по умолчанию пусто).
- **Шаг 6:** итог и **«Попередній прорахунок»** (цена Higgsfield точная, Claude приблизительная по прошлым запускам; для кампании с расписанием ещё сумма за месяц). Кнопки «Почати кампанію» и «Повернутись до налаштувань».
- После запуска кампания видна в карточке проекта («Кампанії проєкту») и в общем списке «Кампанії».

**Раскрытая карточка кампании** (маленькая форма как сейчас) показывает:
1. этапы и текущий этап; 2. % выполнения цикла; 3. витрати по кампании; 4. результаты по каждому агенту; 5. то, что требует внимания; 6. готовые материалы и управление ими (схвалити/повернути/скачать).

**Управление:**
- **Розклад:** по каждому агенту как часто работает (стратегия, креативы, аналитика, отчёты), следующий запуск, правка; общий календарь всех кампаний.
- **Втрутитись у конкретного агента** в конкретной кампании: пауза, своя инструкция только для этой кампании, повтор шага, правка результата руками, комментарий для следующего цикла.
- **Шаблони кампаний**: сохранить настройки и запускать в один клик.
- Жизненный цикл: пауза, архив, копия на другой проект.
- Изоляция: запуск одной кампании не останавливает другие (очередь, приоритеты, лимиты на кампанию).

## 6. Витрати
Только **Claude и Higgsfield** (то, что тратят агенты). Подробно в цифрах и графиках за месяц: по каждому агенту и по каждой кампании; периоды: день, текущий месяц, год, сравнение месяцев. Лимиты и предупреждения.

## 7. Уведомления
- **Telegram:** бот уже работает (токен в Vercel, супергруппа «Mon'Archi HUB», темы «Звіти по проектам», «Нові клієнти»). Для агентов владелец создаёт две темы: «AI Agents: потрібна увага» (креативы готовы, упал шаг, ждёт подтверждения) и «AI Agents: витрати». В настройках темы выбираются так же, как для отчётов.
- **Траты:** по каждой кампании сообщение на каждые **$2 нарастающим итогом** ($2, $4, $6…) плюс одно итоговое сообщение за день.
- **В CRM:** иконка и список уведомлений.
- Подтверждение результатов и расходов: механизм утверждающих, как у отчётов в проектах.

## 8. Память о клиенте и база знаний
- По каждому клиенту системно записывается: что делали, что одобрено или возвращено и почему, комментарии и правки, итоги и результаты рекламы.
- Агент читает краткое **досье клиента** (обновляется после каждого цикла) и подтягивает из архива нужные эпизоды. Через годы клиент вернётся, и агент опирается на записанную историю (не на память модели).
- «Інформаційна база» (процессы, примеры отчётов, переписки, истории работ): сначала как контекст для агентов, потом поиск по смыслу.
- Конфиденциальность: данные уходят в Anthropic; правила, что можно загружать, нужны до наполнения базы.

## 9. Технические условия
- **Лимит по числу креативов нет, лимит по деньгам вместо него.** Стратег делает до 3 направлений за вызов, поэтому большие объёмы делятся на части (направления × форматы × варианты).
- **Очередь:** сейчас cron раз в 15 минут; ускорить (например, `pg_cron` в Supabase раз в минуту вызывает `/api/agent-tick`).
- **Права и журнал:** кто запускает платное и подтверждает траты; журнал действий.
- **Ключи и токены:** создаёт и вставляет в Vercel только владелец; в чат не присылать.
- **Агенты не меняют рекламу в кабинетах** (только предлагают); автоматизация этого позже, по решению владельца.
- Голос: распознавание речи в браузере (Chrome, компьютер и телефон), языки uk/ru/en с переключателем; при недостаточном качестве, на сервере.
- Параллельно: автоподтягивание новых кабинетов Meta (`docs/project-reports-tasks.md`, блок «Новые клиенты»).

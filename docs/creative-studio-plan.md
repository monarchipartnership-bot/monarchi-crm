# Креативна студія: агенти для креативів і текстів (план)

Задача (2026-10-22): клієнт дає вимоги, ланцюжок агентів аналізує його, конкурентів і поточні креативи, збирає ТЗ, пише тексти й через Higgsfield робить креативи, які йдуть на затвердження людині.

## Рішення (узгоджено з користувачем)
- Живе в «AI Agents → Кампанії» (розширюємо команду кампанії, не новий розділ).
- Перші креативи: статичні картинки (відео потім).
- Матеріали клієнта (логотип, фото продукту, приклади стилю) менеджер завантажує у форму запиту, вони йдуть у Higgsfield як референси.
- Нічого не публікується і не вантажиться в рекламні кабінети: результат лише на затвердження.
- Будуємо локально, на прод тільки за словом користувача.

## Схема ланцюжка (один запит = один проход)
```
Запит (форма: вимоги, формати, матеріали)
   ├─ Аналітик клієнта   (вимоги + сайт + поточні креативи)  ┐
   └─ Аналітик конкурентів (сайти конкурентів, приклади)      ┴─> Автор ТЗ ─┬─> Копірайтер креативів (якщо треба текст)
                                                                              └─> Виробник креативів ─> Higgsfield ─> перевірка ─> затвердження
```
Запити живуть окремо від тижневої роботи кампанії: власний запис `ag_creative_requests`, завдання агентів несуть `request_id`.

## Етапи
1. **Етап 1 (без Higgsfield):** форма запиту, 5 ролей (аналітик клієнта, аналітик конкурентів, автор ТЗ, копірайтер, виробник у режимі «готує промти»), ланцюжок за запитом, результати на сторінці запиту, ТЗ у вигляді JSON-концепцій, промти для Higgsfield.
2. **Етап 2:** коротка перевірка Higgsfield API (референси, формати, кирилиця на картинці), виробник картинок, перевірка результату (vision), галерея затвердження («прийняти», «переробити з коментарем»), ліміт витрат.
3. **Етап 3:** відео, варіанти, зворотний зв'язок з результатів реклами.

## Ризики
- Фідельність продукту й логотипу: текст у картинку не довіряємо (кирилиця), продукт тільки з референсів.
- Креативи конкурентів: Meta Ad Library автоматично не вивантажується, аналіз за сайтами й ручними прикладами.
- Для нового клієнта немає даних кабінету: аналітик клієнта працює з сайтом і матеріалами.
- Витрати Higgsfield: ліміт на запит і кількість варіантів.

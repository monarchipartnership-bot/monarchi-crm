# Monarchi CRM

Внутрішня CRM для команди Monarchi — звітність, воронка угод, клієнтська база, автоматизація задач та внутрішні інструменти. React + Vite, дані та авторизація через Supabase.

## Розробка

```bash
npm install
npm run dev
```

## Білд

```bash
npm run build
```

## Деплой

Проєкт підключено до Vercel (git-інтеграція) — кожен пуш у гілку `master` автоматично оновлює продакшн.
